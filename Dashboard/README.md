# 📊 Dashboard

## 📌 Overview

This folder contains all dashboards and visualizations created for the Netflix Data Analysis project using Microsoft Excel, Python, and Power BI.

These dashboards provide an interactive and visual understanding of Netflix content, helping identify trends, content distribution, genres, ratings, countries, and release patterns.

## 📊 Key Insights

- Movies account for a larger share of Netflix content than TV Shows.
- The United States has the highest number of Netflix titles.
- Drama and International Movies are among the most popular genres.
- Netflix has expanded its content library significantly over the years.
- A few directors have contributed multiple titles to the platform.

## 🎯 Purpose

These dashboards were developed to:

- Monitor Netflix content distribution.
- Analyze genres, ratings, and countries.
- Identify content trends over time.
- Present business insights through interactive visualizations.
